15 Open-Source-Alternativen zu teuren Software-Abos

Quelle: „15 Open-Source-Tools, die deine teuren Abos ersetzen" · Julian Ivanov | KI-Automatisierung · 32 Min · automatisch transkribiert

Für fast jedes Software-Abo gibt es eine kostenlose, selbst hostbare Open-Source-Alternative — von Automatisierung und Cloud-Speicher über CRM, Rechnungen und digitale Unterschriften bis zu Passwortmanager und KI-Agent. Am Ende: wie sich alle 15 Tools per One-Click-Install auf einem eigenen Server einrichten lassen, mit Claude Code per SSH als Einrichtungshilfe.

Warum das mehr als nur Geld spart: Laut Berechnung der Harvard Business School würden Unternehmen ohne Open Source rund das 3,5-fache für Software zahlen. In Deutschland setzen laut Bitkom/PwC inzwischen 73 % der Unternehmen Open Source ein (vor zwei Jahren 69 %). Neben den Kosten zählt vor allem die Datenhoheit: Bei selbst gehosteten Tools bleiben Kundendaten, Rechnungen und Dokumente auf der eigenen Infrastruktur statt beim Anbieter.

KI-Interfaces & Automatisierung

01–02
01

n8n

ab 3:58

Automatisierungstool zum Zusammenklicken von Abläufen (z. B. Rechnung rein → Text auslesen → Datenbankeintrag → Benachrichtigung), mit über 500 nativen Integrationen und optionaler KI-Einbindung. GitHub

In Unternehmen eher wichtiger geworden statt weniger, aus drei Gründen: Transparenz (der komplette Prozess liegt sichtbar auf einer Leinwand statt in einem Skript, das niemand mehr versteht), lückenlose Protokollierung jeder Ausführung samt Zwischendaten, und vollständiges Self-Hosting.

02

Open WebUI

ab 5:49

ChatGPT-artige Oberfläche zum Selbsthosten mit freier Modellwahl (eigene API-Keys von OpenAI, Anthropic, Google, Mistral … oder ein lokales Modell), Benutzerverwaltung mit Rechten pro Mitarbeiter sowie durchsuchbaren eigenen Dokumenten samt Quellenangabe. GitHub

Eigene Assistenten lassen sich mit unterschiedlichen Modellen und Dokumenten anlegen. Wichtig: Self-Hosting sichert Oberfläche, Verläufe und Dokumente ab — Anfragen an einen externen Modell-Anbieter gehen weiterhin dorthin.

Dateien & Dokumente

03–05
03

Nextcloud

ab 7:20

Ersetzt Dropbox/Google Drive: eigener Dateispeicher mit Ordnern, Freigabelinks, Versionsverlauf und Sync-Apps für Windows, Mac, Android und iPhone. GitHub

Sensible Unterlagen (Kundenverträge, Personaldaten, Ausweise) bleiben auf dem eigenen Server, Freigaben laufen über passwortgeschützte, automatisch ablaufende Links statt Mail-Anhänge. Bringt zusätzlich Kalender, Kontakte, Aufgaben und Online-Bearbeitung von Office-Dokumenten mit.

04

Paperless-ngx

ab 8:47

Dokumentenmanagement mit automatischer OCR: Dokumente landen in einem Ordner, Paperless liest den Text aus den Bildern aus und macht sie volltextdurchsuchbar — auch wenn der Suchbegriff nur als Bildtext im gescannten Brief steht. GitHub

Eignet sich damit auch, um die komplette Buchhaltung vorzubereiten, bevor sie an den Steuerberater geht.

05

Stirling PDF

ab 9:41

Ersetzt Adobe Acrobat Pro (rund 25 €/Monat) mit über 50 PDF-Funktionen statt der meist genutzten fünf: zusammenführen, aufteilen, drehen, verkleinern, Office-Dateien umwandeln, OCR auf gescannten Seiten, schwärzen, Wasserzeichen setzen, signieren. GitHub

Läuft komplett auf dem eigenen Server oder Gerät.

Daten, CRM & Business

06–10
06

NocoDB

ab 10:29

Ersetzt Airtable: Datenbank mit Tabellen-Oberfläche (Spaltentypen wie Datum, Auswahl, Datei, Verknüpfung zu anderen Tabellen) und mehreren Ansichten — Tabelle, Kanban, Kalender, Galerie. GitHub

Besonders nützlich in Kombination mit n8n: Automatisierungen lesen und schreiben direkt in denselben Tabellen, z. B. ausgelöst durch die Änderung eines Auswahlfelds.

07

Twenty (CRM)

ab 11:50

Open-Source-CRM: Firmen und Personen anlegen und verknüpfen, Zeitleiste mit Notizen pro Kontakt, Angebote durch eine Pipeline ziehen, um offen liegendes Geld sichtbar zu machen, eigene Dashboards für Umsatz- und Deal-Zahlen. GitHub

Über n8n lassen sich z. B. neue Kontaktformular-Anfragen automatisch samt Notiz und Quelle als Kontakt anlegen, statt sie per Hand nachzupflegen.

08

Cal.com

ab 13:12

Ersetzt Calendly & Co. (dort oft rund 15 €/Monat): öffentlich buchbare Termin-Events mit Kalenderabgleich, frei anpassbaren Vorab-Abfragen sowie automatischen Bestätigungs- und Erinnerungsmails inklusive Video-Link. GitHub

Optional lässt sich vor der Buchung eine Zahlung (z. B. über Stripe) vorschalten.

09

Invoice Ninja

ab 14:29

Deckt Rechnungen und Zeiterfassung komplett ab: Kunden anlegen, Angebote per Klick in Rechnungen umwandeln, wiederkehrende Rechnungen automatisieren und automatische Zahlungserinnerungen nach festgelegtem Zeitplan verschicken. GitHub

Eingebauter Timer pro Projekt übernimmt erfasste Stunden direkt in eine Rechnung — bei Abrechnung nach Stunden spart das ein zweites Tool.

10

DocuSeal

ab 15:19

Ersetzt DocuSign/PandaDoc (dort je nach Paket 25–45 €/Monat): Dokument hochladen, Unterschrift-, Datums- und Namensfelder platzieren, Link verschicken — der Empfänger unterschreibt im Browser, das fertige Dokument kommt inklusive Protokoll zurück (wer, wann, von wo). GitHub

Lässt sich mit n8n verknüpfen, um nach einer Unterschrift automatisch z. B. einen Onboarding-Prozess auszulösen.

Kommunikation, Daten & Sicherheit

11–15
11

Typebot & Chatwoot

ab 16:39

Typebot baut Chatbots per Drag-and-Drop für Website, WhatsApp & Co., inklusive KI-Anbindung und n8n-Trigger während des Gesprächs; Statistiken zeigen, an welcher Stelle Besucher aussteigen. Typebot auf GitHub

Für größeren Kundensupport bündelt Chatwoot — die selbst gehostete Alternative zu Zendesk/Intercom — Mail, WhatsApp und Instagram an einer zentralen Stelle.

12

Postiz

ab 18:10

Plant und veröffentlicht Social-Media-Beiträge kanalübergreifend (LinkedIn, Instagram, Facebook, X, TikTok …) über einen Kalender, mit pro Kanal angepassten Textvarianten. GitHub

KI-Agenten (Claude Code, Codex, Hermes …) lassen sich zum gemeinsamen Verfassen der Beiträge anknüpfen. Kommerzielle Alternativen kosten meist 15–25 €/Monat gestaffelt nach Kanalzahl, zusätzlich pro verwaltetem Kundenaccount.

13

Supabase

ab 19:34

Backend-Baustein für alles, was eine von einer KI gebaute App noch braucht: eine Postgres-Datenbank mit Authentication, Edge Functions, Echtzeitdaten, Datei-Speicher und Vektor-Embeddings für eigene RAG-Systeme. GitHub

Alles in einer Oberfläche inklusive Table-Editor und SQL-Editor — keine separate Vektordatenbank nötig.

14

Vaultwarden

ab 21:20

Selbst gehosteter, Bitwarden-kompatibler Passwortmanager-Server: Die offiziellen Bitwarden-Apps (Browser, Handy, Windows/Mac) verbinden sich einfach mit der eigenen Serveradresse, der Tresor bleibt aber bei dir statt beim Anbieter. GitHub

Zugänge lassen sich gezielt an Mitarbeiter freigeben statt sie per Mail/WhatsApp zu verschicken; ein Bericht zeigt schwache und mehrfach verwendete Passwörter. Läuft mit rund 256 MB Arbeitsspeicher.

15

Hermes Agent

ab 23:08

Autonomer KI-Agent für die eigene Hardware (z. B. Mac Mini oder Server), der 24/7 erreichbar ist, Aufgaben eigenständig erledigt und mit jeder Aufgabe dazulernt.

Erreichbar per Messenger (WhatsApp, Telegram) oder über eine eigene Desktop-App — laut Video aktuell der beste durchgehend erreichbare autonome KI-Agent.

Nicht jedes Tool ist Pflicht: Erst den konkreten Bedarf klären, dann das passende Tool einsetzen — nicht umgekehrt, nur weil es die Liste hergibt.

Alles auf einem eigenen Server einrichten

16–18
16

Eigener Server

ab 25:04

Alle 15 Tools brauchen als Basis einen eigenen Server, damit sie 24/7 von überall erreichbar sind. Im Video wird Hostinger genutzt (ab rund 8 €/Monat für deutlich mehr Rechenleistung, als man für einzelne Abo-Tools zahlen würde) — bei der Bestellung sind Docker und Traefik als Anwendungen auszuwählen.

Danach lassen sich fast alle vorgestellten Tools über den Docker-Manager-Katalog per One-Click-Install installieren — nur Open WebUI und Supabase müssen manuell eingerichtet werden.

17

Claude Code per SSH mit dem Server verbinden

ab 26:46

Statt sich allein durch Server-Dokumentation zu kämpfen, verbindet man Claude Code (oder Codex) per SSH direkt mit dem Server: in der Claude-Code-Desktop-App über den Arbeitsbereich den Bereich SSH wählen.

Claude kann dann installierte Programme auflisten, bei der Einrichtung einzelner Tools helfen, fehlende Parameter erklären — oder sogar zusätzliche Software installieren, die der Hoster nicht als One-Click-Vorlage anbietet.

18

SSH-Schlüssel anlegen und verbinden

ab 28:43

Bei Hostinger unter Einstellungen → SSH-Schlüssel einen neuen Schlüssel erzeugen (Public Key dort eintragen, Private Key bleibt lokal — ein Coding-Agent kann diesen Schritt auch übernehmen).

In Claude Code unter dem Arbeitsbereich → SSH → SSH-Verbindung hinzufügen: Gerätename, SSH-Host (Benutzername@IP-Adresse) und Port eingeben, Verbindung testen und einmalig mit dem Root-Passwort anmelden. Als Arbeitsordner empfiehlt sich das Root-Verzeichnis, damit Claude Code Zugriff auf den gesamten Server hat.
