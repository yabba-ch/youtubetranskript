Zehn Skills & Plugins, die Claude Code wirklich stärker machen

Quelle: „Die 10 besten Claude Code Skills & Plugins" · Julian Ivanov | KI-Automatisierung · 42 Min · automatisch transkribiert

Claude Code ist von Haus aus stark — richtig mächtig wird es erst mit Zugang zu guten Skills und Plugins. Ein Skill ist im Kern nur eine Markdown-Datei mit Anweisungen, die Claude sich selbst zieht, sobald er sie braucht. Ein Plugin ist ein Skill plus zusätzliche Komponenten — Referenzdateien, Scripts oder ein MCP-Server.

Skill

Textdatei mit Anweisungen

Wie ein fest hinterlegter Prompt. Claude erkennt aus dem Kontext, wann er passt, liest ihn aus und wendet die Anleitung an — z. B. wie ein Videoskript strukturiert werden soll.

Plugin

Skill + Zusatzkomponenten

Dieselbe Skill-Datei, ergänzt um Referenzdateien, Python-Scripts oder einen MCP-Server, die bei der Installation mitgeliefert werden.

Installationsmuster (für fast alle Einträge gleich): GitHub-Link des Repositories kopieren, in Claude Code einfügen und schreiben installiere diesen Skill — am besten im bypass permissions-Modus. Faustregel aus dem Video, in der CLAUDE.md hinterlegt: „Alle Skills und MCP-Server werden immer auf Projektebene installiert" — nicht global auf User-Ebene.

Excalidraw Diagram Skill

Skill ab 3:53
Warum

Erstellt Diagramme und Prozessabbildungen automatisch als PNG und als Excalidraw-JSON — für kostenlose, frei editierbare Whiteboards. Der Clou: Claude schaut sich das generierte Bild selbst an und korrigiert überlappende Boxen oder falsch gerichtete Pfeile eigenständig.

Installation
> installiere diesen Skill (Link: github.com/coleam00/excalidraw-diagram-skill)
Funktionsweise

Skill-Ordner mit Referenzdateien (Farbpaletten, Elementtypen, JSON-Schema) und einem Python-Script. Claude generiert das Diagramm, prüft es visuell, passt es bei Bedarf an — danach JSON in excalidraw.com einfügen und frei weiterbearbeiten.

Use Case

Architekturreviews, Prozessabbildungen, Dokumentationen — ein kurzer Text-Prompt reicht, Feedback in ein bis zwei Runden verfeinert das Ergebnis.

github.com/coleam00/excalidraw-diagram-skill excalidraw.com
02

NotebookLM-py

Skill (Python-Library) ab 7:53
Warum

Gibt Claude Code vollen programmatischen Zugriff auf Googles NotebookLM — kostenlos. Claude kann damit recherchieren, eine Wissensdatenbank abfragen und Podcasts, Slides, Quizze und Infografiken erzeugen. Alle Antworten sind quellenbasiert.

Installation
> installiere diesen Skill für mich (Link: github.com/teng-lin/notebooklm-py)
anschließend im Terminal: Login-Befehl ausführen → Google-Account im Browser autorisieren
Funktionsweise

Direkter Aufruf per Slash-Command möglich (/notebook-lm), oder Claude erkennt den passenden Moment aus dem Kontext. Claude legt selbstständig ein Notebook an, startet eine Tiefenrecherche, befragt NotebookLM per Chat und erstellt daraus Podcast und Infografik — inklusive Nano-Banana-2-Bildmodell für die Grafik.

Use Case

„Erstelle ein Notebook, recherchiere die Top-10-Videos zum Thema, ranke die beliebtesten Skills und erstelle dazu Podcast und Infografik" — komplett ohne externe Zusatz-Tools.

github.com/teng-lin/notebooklm-py

Remotion Best Practices Skill

Skill ab 13:24
Warum

Lässt Claude Code echte gerenderte MP4-Videos erzeugen — per Code, nicht per KI-Videogenerator. Vorteil gegenüber generierten Videos: einzelne Abschnitte lassen sich gezielt per Prompt nachbessern, ohne das ganze Video neu zu erzeugen.

Installation
Command von skills.sh im Terminal ausführen, oder > installiere diesen Skill (Link: skills.sh/remotion-dev/skills/remotion-best-practices)
Funktionsweise

Liefert domänenspezifisches Wissen zu Animationen, Kompositionen, Timing, Medien, 3D und Charts in Remotion. Ein Prompt genügt für einen ersten Entwurf; gezieltes Feedback („Karten langsamer einblenden, Text durch eine Illustration ersetzen") passt einzelne Phasen an. Fertiges Video wird direkt gerendert und heruntergeladen.

Use Case

Erklär-Animationen für YouTube-Videos — im Video selbst so für die beiden Intro-Animationen genutzt.

Context7 CLI

CLI + Skill ab 18:04
Warum

Löst das Problem veralteter Trainingsdaten: Sprachmodelle können APIs oder Endpunkte halluzinieren, die gar nicht mehr existieren. Context7 lädt aktuelle API-Dokumentation direkt in den Kontext — kein veralteter Code mehr.

Installation
> installiere Context7 CLI mit dem Skill (Link: github.com/upstash/context7)
optional: API-Key im Context7-Dashboard erstellen → höhere Rate-Limits (auch kostenlos ohne Key nutzbar)
Funktionsweise

CLI + Skill statt MCP-Server — deutlich tokeneffizienter. Bei Fragen zu externen Diensten durchsucht Claude via CLI gezielt die passende Dokumentation, statt eine allgemeine Websuche zu machen — besonders wertvoll bei umfangreicher, mehrseitiger Doku.

Use Case

Z. B. eine Stripe-Checkout-Session korrekt implementieren, mit aktueller Anleitung direkt aus der Stripe-Dokumentation statt aus veraltetem Trainingswissen.

github.com/upstash/context7 context7.com

Firecrawl CLI + Skill

CLI + Skill ab 20:51
Warum

Claudes eingebaute Webfetch-Funktion ruft nur einzelne Seiten ab, rendert kein JavaScript und kann nicht gezielt strukturierte Daten extrahieren. Firecrawl crawlt ganze Websites inklusive Unterseiten, rendert JavaScript, liefert sauberes Markdown oder JSON — inklusive Anti-Bot-Handling.

Installation
> installiere Firecrawl CLI und den Skill, aber nicht den MCP-Server (Link: github.com/firecrawl/cli)
anschließend Terminal-Befehl zur Autorisierung ausführen. Free-Tier: 500 Seiten / Monat.
Funktionsweise

Skill liefert Claude die Kernbefehle zum gezielten Scrapen, Crawlen und strukturierten Extrahieren (z. B. „nur Preise und Feature-Namen als JSON").

Use Case

„Suche 100 Handwerksbetriebe im Umkreis von Hamburg, extrahiere Firmenname, Ansprechpartner, E-Mail, Services und Standort, gib mir das als Excel zurück" — inklusive automatischem Nachschauen im Impressum.

github.com/firecrawl/cli firecrawl.dev

Playwright CLI (Microsoft)

CLI ab 24:23
Warum

Alternative zur Claude-Chrome-Extension zur Browsersteuerung. Statt per Screenshot zu raten, wo geklickt werden muss, analysiert Playwright den Seitencode direkt (IDs, Elemente) — schneller und zuverlässiger, standardmäßig headless.

Installation
> installiere CLI und Skill (Link: github.com/microsoft/playwright-cli)
Funktionsweise

Claude liest den Code der Seite aus, erkennt Feld- und Button-Referenzen direkt und führt Aktionen entsprechend aus — mehrere Sessions parallel möglich; auf Wunsch sichtbar im echten Browser-Tab statt headless.

Use Case

„Nutze Playwright und erstelle Todos für den Haushalt, hake sie nacheinander ab, zeige den Browser an" — in unter einer Minute erledigt.

github.com/microsoft/playwright-cli

Obsidian Skills

Plugin ab 27:42
Warum

Obsidian speichert Notizen als reine Markdown-Dateien — passt perfekt zu Claude Code. Mit dem CLI-Zugriff wird Claude zum persönlichen Assistenten, der das eigene Wissenssystem („zweites Gehirn") als Kontext nutzen kann, statt bei jedem Chat bei null anzufangen.

Installation
Obsidian Desktop-App installieren → neuen Vault (leeren Ordner) anlegen → Ordner in VS Code öffnen
> installiere dieses Obsidian-Plugin (Link: github.com/kepano/obsidian-skills)
Funktionsweise

Installiert automatisch die Obsidian-CLI und weitere Skills. Claude erhält direkten Zugriff auf Vault, Ordner und Notizen: lesen, durchsuchen, zusammenfassen, neue Notizen mit automatischen Verlinkungen anlegen.

Use Case

Mit Claude eine sinnvolle Ordnerstruktur erarbeiten, dann z. B. per Sprachmemo (Whisper-Transkription) Wissen über sich selbst einsprechen — Claude erstellt und verknüpft daraus automatisch Notizen.

github.com/kepano/obsidian-skills obsidian.md

Feature Dev Plugin

Plugin · Anthropic ab 33:05
Warum

Führt die Entwicklung neuer Features strukturiert durch sieben klar getrennte Phasen statt ins Blaue hinein zu coden — mit parallelen Sub-Agenten für Exploration, Architektur und Review.

Installation
> installiere Feature Dev (Link: github.com/anthropics/claude-code, Plugin „feature-dev")
Funktionsweise

1 Discovery (Anforderungen klären) · 2 Codebase-Exploration (2–3 parallele Explorer-Agenten) · 3 Rückfragen (Edge Cases, Fehlerbehandlung) · 4 Architektur-Design (mehrere Varianten zur Auswahl) · 5 Implementierung · 6 Qualitätsreview (3 parallele Review-Agenten) · 7 Zusammenfassung (Doku, Entscheidungen, nächste Schritte).

Use Case

Neue, klar abgegrenzte Features in bestehenden Apps: Login-System, Stripe-Zahlung, Kontaktformular, Suchfunktion.

github.com/anthropics/claude-code

Superpowers Plugin

Plugin ab 36:01
Warum

Das laut Video zweitmeist-heruntergeladene Plugin für Claude Code. Deckt — anders als Feature Dev — den gesamten Entwicklungsprozess ab: nicht nur „baue dieses Feature", sondern auch „hilf mir erst herauszufinden, was ich überhaupt bauen soll".

Installation
> installiere Superpowers (Link: github.com/obra/superpowers)
Aktivierung/Übersicht über /plugins → Manage Plugins
Funktionsweise

Kombiniert Brainstorming, testgetriebene Entwicklung, systematisches Debugging, Subagenten-gesteuerte Entwicklung und Codeprüfung. Bei der testgetriebenen Entwicklung schreibt Claude zuerst die Tests als Anforderungsdefinition und codiert erst danach, bis sie bestehen. Während des Brainstormings kann Claude sogar visuelle UI-Stilrichtungen im Browser zur Auswahl anzeigen.

Use Case

„Erstelle ein Freelancer-CRM-System mit allen nötigen Funktionen" — Claude klärt Anforderungen, zeigt drei UI-Stilrichtungen zur Auswahl, entwirft das Datenmodell und lässt bei jedem Schritt Feedback zu.

github.com/obra/superpowers

CLAUDE.md Management Plugin

Plugin · Anthropic ab 40:23
Warum

Die CLAUDE.md wirkt wie ein Systemprompt, der bei jeder Session mitgeladen wird — wird aber meist einmal geschrieben und nie wieder gepflegt, obwohl sich Projekte laufend weiterentwickeln.

Installation
> installiere das CLAUDE.md Management Plugin (Link: github.com/anthropics/claude-plugins-official, Plugin „claude-md-management")
Funktionsweise

Zwei Funktionen: eine Audit-Funktion, die alle CLAUDE.md-Dateien im Projekt anhand von Qualitätskriterien prüft (aktuell? kompakt genug? wichtige Regeln enthalten?), und der Befehl Revise CLAUDE.md, der am Ende einer Sitzung neue Erkenntnisse einträgt. Änderungen werden vor der Übernahme immer erst angezeigt.

Use Case

Die CLAUDE.md über ein längeres Projekt hinweg aktuell, kompakt und wirklich nützlich halten — statt sie einmal zu schreiben und zu vergessen.

github.com/anthropics/claude-plugins-official
