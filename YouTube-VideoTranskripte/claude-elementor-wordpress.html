WordPress-Design mit Claude & Elementor bauen lassen

Quelle: „Build A WordPress Website in 2026 Using Claude & Elementor (Free AI Tutorial)" · incomtech · 14 Min · automatisch transkribiert (Englisch)

Vier kostenlose Tools im Zusammenspiel bauen eine komplette WordPress-Seite, ohne dass man selbst in Elementor herumklicken muss: Google Stitch entwirft das Design, ChatGPT schärft den Prompt dafür, Claude übersetzt das fertige Design in eine importierbare Elementor-Vorlage — Elementor übernimmt nur noch den Import und den Feinschliff.

Prompt

ChatGPT

Nimmt eine kurze, grobe Beschreibung der Wunsch-Website und macht daraus einen detaillierten, strukturierten Prompt für Google Stitch.

Design

Google Stitch

Generiert aus dem Prompt ein komplettes Designsystem (Farben, Fonts, Buttons, Logo) plus fertige Unterseiten als Web-App-Entwurf.

Umwandlung

Claude

Bekommt das Stitch-Designsystem (Markdown) und den Seitencode und baut daraus eine importierbare Elementor-JSON-Vorlage.

Umsetzung

Elementor

WordPress-Page-Builder, der die JSON-Vorlage importiert — Feinschliff bei Abständen, Header und Footer bleibt manuell.

01

Einen guten Prompt schreiben

ab 1:00
Warum

Ein grob formulierter Wunsch reicht meist nicht für ein gutes KI-Design. ChatGPT wird deshalb nur als Prompt-Verstärker genutzt, bevor der eigentliche Design-Prompt bei Google Stitch landet.

Beispiel-Prompt für ChatGPT
I am writing a prompt to design a website using Google Stitch. I want you to enhance my prompt, make it more detailed so the design will be perfect. Create a design for a website for a phone repair business called Phone Repair. Use modern light colors. I want you to design these pages: home, repair services, about us, contact. Every hero section should have an image background of full width with a darker overlay on which the title and paragraph for that page is displayed. I want you to include the following sections: reviews, visit us, why us, our expertise, and call to action.
Funktionsweise

ChatGPT liefert daraus einen ausführlichen, strukturierten Prompt zurück — inklusive Farbpalette, UI-Stil und exakter Seitenstruktur — der direkt in Google Stitch eingefügt wird.

02

Design mit Google Stitch AI

ab 3:26
Warum

Google Stitch übernimmt die komplette Gestaltungsarbeit — von der Farbwelt bis zu fertigen Unterseiten — ausgehend von einem einzigen Text-Prompt.

Funktionsweise

Beim Erstellen „Web" statt App auswählen, den ChatGPT-Prompt einfügen und generieren lassen. Stitch erzeugt ein Designsystem (Farben, Schriften, Button-Stile) samt Logo und alle angefragten Unterseiten (z. B. Home, Services, About, Contact) als fertige Entwürfe.

03

Elementor-Vorlage mit Claude erzeugen

ab 5:38
Warum

Der eigentliche Automatisierungsschritt: Claude übersetzt das visuelle Stitch-Design in eine Elementor-kompatible JSON-Vorlage, damit niemand die Seite von Hand in Elementor nachbauen muss.

Vorbereitung

In Stitch beim Designsystem auf „Edit" gehen und die design.md-Datei kopieren. Danach die gewünschte Seite öffnen, „Export" → „Copy code to clipboard".

Prompt für Claude
Create a JSON file for an Elementor website template based on the design system I have uploaded as a markdown file. The template must be for a home page. I also added the code for the home page to this prompt. Use that to create an Elementor JSON file that I can upload as a template.
Funktionsweise

Beide kopierten Inhalte (design.md und der exportierte Seitencode) zusammen mit dem Prompt in Claude einfügen. Claude erklärt kurz sein Vorgehen und liefert anschließend die vollständige JSON-Datei zum Kopieren.

04

Import in Elementor

ab 7:42
Funktionsweise

Die von Claude gelieferte JSON in eine Datei speichern (im Video z. B. per VS Code). In WordPress eine neue Seite mit Template Elementor Full Width anlegen, veröffentlichen und mit Elementor bearbeiten. Dort auf „Templates" → im Elementor-Bibliothek-Panel den Reiter „Templates" → „Upload" und die JSON-Datei auswählen. Nach einer kurzen Warnung („Don't show this message again" → „Continue") wird die Vorlage erfolgreich importiert.

05

Feinschliff

ab 9:30
Worauf achten

Claude erzeugt gelegentlich einen reinen HTML-Block statt echter Elementor-Container — in dem Fall lohnt sich eine Rückfrage an Claude, das zu korrigieren. Bilder werden beim Import nicht automatisch mitgeliefert: Sie müssen einzeln aus Google Stitch gespeichert (Rechtsklick → Bild speichern) und in Elementor neu eingesetzt werden.

Header & Footer

Werden separat über den Elementor Theme Builder angelegt: neuen Header bzw. Footer erstellen, vorhandenen Inhalt entfernen und den passenden, aus Stitch exportierten Code einfügen.

Feintuning

Kleinere Abstände (Columns Gap, Margin) lassen sich wie gewohnt direkt in Elementor anpassen und dann auf die anderen Sektionen übertragen — der Rest der Seite braucht laut Video nur noch punktuelles Nacharbeiten.
