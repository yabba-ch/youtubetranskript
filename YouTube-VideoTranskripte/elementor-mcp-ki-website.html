Elementor MCP – KI baut deine WordPress-Website

Quelle: „Elementor MCP (NEU) – KI baut jetzt deine WordPress-Website!" · Alex von EXPERTE.de · 23 Min · Deutsch

Praxis-Tutorial zum neuen offiziellen Elementor MCP-Server (ab Elementor 4.3). Gezeigt wird der komplette Weg, um mit Claude eine WordPress-Website in Elementor bauen zu lassen – und sie danach wie gewohnt per Klick weiterzubearbeiten. MCP schliesst damit die Lücke zwischen „KI baut auf Knopfdruck" und „volle Freiheit im Page Builder".

Einordnung: Dasselbe Muster wie beim Elementor-Produktvideo – ein Plugin exponiert einen MCP-Server, die Authentifizierung läuft über ein widerrufbares Application Password (= WordPress REST API, also weitreichender Zugriff). Entscheidend: Es entstehen native, weiter pflegbare Elementor-Seiten statt KI-Wegwerf-Artefakte. Diese deutschsprachige Variante liefert konkrete Prompt-Vorlagen und ein durchgespieltes Kunden-Beispiel.

Workflow Schritt für Schritt

01–08
01

Was der Elementor MCP ist

ab 1:42

MCP (Model Context Protocol) ist ein gemeinsamer Standard, über den eine KI wie Claude oder Codex ein Programm wie Elementor direkt bedient – wie ein Adapter. Ohne ihn kann die KI nur sagen, wo man klicken muss; mit ihm erledigt sie die Aufgabe selbst. Ab Elementor 4.3 legt Claude damit Seiten an, baut Abschnitte und setzt Farben und Schriften.

Wichtig: Es entstehen ganz normale Elementor-Seiten – jeder Text, jedes Bild bleibt selbst anklickbar und anpassbar. Einige Funktionen gibt es nur mit Pro:

FunktionFreePro
Seiten & Abschnitte bauen✓✓
Farben & Schriften als globale Variablen✓✓
Grösse/Abstände über globale Variablen–✓
Kopf-/Fusszeile & Theme-Builder–✓
Wiederverwendbare Komponenten–✓
Pop-ups–✓
02

Was du dafür brauchst

ab 3:43

Elementor Pro (rund 49 € / Jahr pro Website, im Video wegen Kopf-/Fusszeile genutzt), ein WordPress-Hosting (z. B. Hostinger) und ein KI-Abo – Claude Pro (~17–20 €/Monat) oder Codex von OpenAI.

03

MCP-Server einrichten

ab 4:14

Elementor-Plugin auf die neueste Version bringen (im Video 4.3.2). Dann Elementor → Elementor MCP öffnen, Enable MCP Access, Zielanwendung wählen (z. B. Claude Code) und Generate Prompt – der fertige Konfigurations-Prompt erscheint zum Kopieren.

In der Desktop-App von Claude in den Code-Bereich wechseln (Seitenleiste → Code-Button), den Prompt einfügen und absenden. Claude trägt die Zugangsdaten ein (1–2 Min.); danach einen neuen Chat öffnen. Achtung: Das generierte Application Password ist die WordPress REST API und gibt weitreichenden Zugriff auf die ganze Website – nicht öffentlich zeigen, sonst danach zurücksetzen.

04

Lokale Website erstellen lassen

ab 6:59

Für eine neue Website die Seite zuerst lokal von Claude bauen lassen (läuft dann z. B. unter localhost:8412). Alex stellt dafür drei kostenlose Prompt-Vorlagen auf einer Notion-Seite bereit (planen & bauen / nach Elementor bringen / weitere Seiten). Unter der gestrichelten Linie die Platzhalter ersetzen (Firma, Tätigkeit, Ort).

Claude gibt zuerst eine Übersicht der geplanten Seiten und fragt fehlende Infos nach (z. B. Telefonnummer). Bauzeit ~20–30 Min. Kleine Wünsche (Logo, Design, Abstände) am einfachsten direkt im Chat korrigieren lassen.

05

In Elementor nachbauen lassen

ab 10:25

Über die MCP-Verbindung baut Claude die lokale Website in Elementor nach (Prompt-Vorlage 2). Vorher sicherheitshalber prüfen lassen, ob das MCP für die Domain funktioniert. Dauer wieder ~20–30 Min.

Ergebnis: veröffentlicht inkl. sechs Unterseiten, Kopf-/Fusszeile als eigene Vorlage und funktionsfähigem Antragsformular. Als Theme dient das Hello Theme. In die Vorlage ist ein visueller Check eingebaut (Desktop, Tablet, Smartphone). Die Elementor-Seite sieht praktisch 1:1 wie die lokale Version aus.

06

In Elementor bearbeiten

ab 14:26

Der eigentliche Vorteil: Kleine Änderungen (Text, Bild) laufen nicht mehr über einen neuen Prompt, sondern direkt im Elementor-Editor per Klick. Unter Seiten alle von der KI gebauten Seiten → „Mit Elementor bearbeiten".

Die Oberfläche ist der neue Atomic Editor (unabhängig vom MCP, einfach die neueste Elementor-Variante). Die Abschnitte im Navigator sind von der KI sauber benannt, damit man sich zurechtfindet.

07

Theme-Builder nutzen

ab 16:48

Globale Design-Änderungen laufen über den Theme-Builder, nicht über die KI: dort liegen Kopf-/Fusszeile, Pop-ups und wiederkehrende Vorlagen. Globale Farben & Schriften stehen im Designsystem → Variablen; diese Variablen werden in Klassen verwendet (z. B. „Überschrift Hero"), die die KI im Atomic Editor angelegt hat.

Datenschutz-Tipp: Schriften lokal laden statt von Google Fonts einbetten – unter Elementor → Einstellungen → Leistung „Google Fonts lokal laden" aktivieren, damit beim Besucher keine Verbindung zu Google aufgebaut wird.

08

Neue Seite hinzufügen

ab 20:40

Prompt-Vorlage 3 für zusätzliche Seiten auf einer bestehenden Website. Beispiel: Ein Kunde schickt ein Word-Dokument mit Infos zu neuen Mitarbeitenden → an Claude weitergeben → nach wenigen Minuten ist eine Karriereseite live, im Menü verlinkt, mit passend gewählten Bildern und übernommenem Design.

Fazit: Der grösste Nutzen liegt bei neuen Websites; danach kann man ohne KI-Abo direkt in WordPress weiterarbeiten. Beides – KI auf Knopfdruck und kleine manuelle Änderungen – in einem Tool.
