Elementor MCP Webinar – Websites live mit Claude bauen

Quelle: „Introducing the Elementor MCP | Webinar with Roi & Miriam, featuring Ferdy" · Elementor · 65 Min · aus dem Englischen übersetzt

Offizielles Webinar zur Vorstellung des Elementor MCP (seit Version 4.3 offiziell raus). Kern ist eine lange Live-Demo: Miriam baut den Gewürz-Shop «Nine Spices» von Grund auf mit Claude über das MCP. Das MCP erzeugt dabei native, voll bearbeitbare Elementor-Strukturen – «hybrid vibe coding», bei dem die KI das Repetitive übernimmt und der Mensch die Kontrolle behält.

Einordnung: Das MCP ist die ausführliche Vertiefung zum kompakten How-to „Elementor MCP einrichten". Es trägt weiter als reiner Seitenbau: Content-Pflege, WooCommerce und sogar E-Mail-getriggerte Änderungen laufen über denselben KI-Client. Angie stützt sich auf die WordPress Abilities API und macht so beliebige Plugins (hier ACF) für die KI nutzbar; der KI-Client wirkt als Orchestrator über mehrere MCP-Server.

Grundlagen & Verbindung

01–02
01

Konzept: echte, bearbeitbare Strukturen

ab 2:10

Das MCP verbindet eine Elementor-Site mit MCP-fähigen KI-Tools (Claude, Codex, Cursor) und erzeugt native, echte Elementor-Strukturen – voll im Editor bearbeitbar, wie selbst gebaut. Roi nennt es «hybrid vibe coding»: die KI übernimmt das Repetitive, der Mensch behält die Kontrolle. Alles kommt als Draft rein, man prüft und veröffentlicht selbst.

02

Verbindung einrichten

ab 5:19

WP-Admin → Elementor → Elementor MCP → MCP-Zugriff aktivieren → Tool wählen (Claude Code/Desktop, Codex, Cursor oder andere) → Checkbox für das Application Password bestätigen → «Generate Prompt» (enthält das Passwort, wird automatisch kopiert) → in Claude einfügen und senden. Kein manuelles JSON-Config-Editieren mehr.

Live-Demo: Nine Spices

03–07
03

Nine Spices mit Claude gebaut

ab 6:42

Die komplette Demo-Site (ein Gewürz-Shop) entstand mit Claude: 18 Variablen, 75 Klassen, Site-Parts, alle Seiten und Templates, ACF Custom Fields, Angie-Snippets und der gesamte Content. Mit architektonischem Denken – Rezepte verknüpfen die verwendeten Gewürze, die der Nutzer direkt in den Warenkorb legen kann.

04

Gast Ferdy: Praxisbeispiele

ab 9:41

Der niederländische Webcreator Ferdy hat seine von einer Agentur gebaute Site mit dem MCP nachgebaut: Hover-Effekte, schwebende Tutorials, eine Knowledge-Area mit Custom Post Types, ein von einer Award-Site inspiriertes Layout aus Screenshots. Sein Bild: «wie ein Webdesigner neben dir». Prompts gehen in jeder Sprache; Claude versteht die Absicht auch in gebrochenem Englisch.

05

Bilder aus der Media Library

ab 29:03

Claude erkennt Bildinhalte visuell und platziert passende Bilder aus der Media Library auf der Homepage. Dafür nutzt es Angies execute PHP, um die Media Library zu erreichen – das ist eine WordPress-Capability, keine Elementor-Funktion.

06

Neues Rezept end-to-end

ab 35:47

Claude recherchiert trendige Rezepte, schlägt drei vor (Schawarma gewählt), füllt die ACF-Felder, trifft die Brand Voice und verknüpft die passenden Produkte. Weil ACF free keine Repeater-Felder hat, baut Angie einen Workaround mit Pipe-Format für eine zweispaltige Zutatenliste.

07

Konverter, Favicon & Client-E-Mail

ab 44:06

Claude baut einen Gramm↔Unzen-Konverter als Angie-Snippet und erzeugt parallel in einer zweiten Session ein Favicon. Höhepunkt: Claude liest über die Gmail-Anbindung eine Kunden-E-Mail («Zatar jetzt als 500-g-Glas») und ergänzt eigenständig die WooCommerce-Produktvariante.

Über verkettete MCPs (Figma, Drive, Slack, WhatsApp) lassen sich so ganze Workflows und Automationen rund um die Site bauen – die Website ist nur ein Werkzeug im Werkzeugkasten.

Einordnung & Praxis

08–10
08

Angie vs. Elementor MCP

ab 16:44

Beide ergänzen sich – am besten beide installiert. Claude entscheidet selbst, welches Tool es nutzt; man muss es nicht vorgeben. Angie stützt sich auf die WordPress Abilities API, kann Fähigkeiten für andere Plugins erzeugen (siehe ACF) und PHP ausführen; das Elementor MCP ist auf den Seitenaufbau spezialisiert.

09

Workflow-Empfehlung

ab 23:50

Erst mit Claude planen (Spec), dann HTML-Prototypen (schnell, nicht an WordPress gebunden), drei Design-Richtungen generieren, dann «build it» → echte Elementor-Struktur. Output immer prüfen und nachjustieren. Jede Session ist eine saubere Session (Memory-Files für Allgemeines) – Arzt-Analogie: der Arzt zieht deine Akte, erinnert sich nicht an alles.

10

Preise, Technik & Fazit

ab 49:58

Die MCP-Verbindung ist gratis; Kosten entstehen nur durch das eigene KI-Tool (Abo/Credits). Elementor-seitig: Core gratis, Pro-Features (Formulare, Pop-ups, dynamische Inhalte) brauchen Pro. Das MCP arbeitet aktuell am besten mit V4 Atomic Structures (Atomic Editor aktivieren); V3-Support ist in Arbeit.

Fazit: «Wir werden alle zu Direktoren.» Der Human-in-the-loop bleibt zentral. Empfehlung: auf einer Staging-Kopie testen und immer Backups machen.
