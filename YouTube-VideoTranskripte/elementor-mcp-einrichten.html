Elementor MCP einrichten mit Claude, Codex oder Cursor

Quelle: „How to set up the Elementor MCP with Claude, Codex, or Cursor" · Elementor · 5 Min · aus dem Englischen übersetzt

Das offizielle Elementor MCP verbindet KI-Tools wie Claude, Codex und Cursor mit einer Elementor-Website. Die KI erzeugt dabei echte, nativ bearbeitbare Elementor-Strukturen – kein gesperrter Inhalt, kein Code, kein Einmal-Design. Roy von Elementor zeigt die Einrichtung Schritt für Schritt.

Einordnung: Das Plugin exponiert einen MCP-Server; die Authentifizierung läuft über pro Client getrennte Application Passwords, die einzeln widerrufbar sind. Über die WordPress Abilities API werden auch andere Plugins steuerbar. Entscheidend: Statt KI-generierter Wegwerf-Artefakte entstehen native, im Zielsystem weiter pflegbare Elementor-Elemente.

Einrichtung Schritt für Schritt

01–04
01

Elementor & Erweiterungen installieren

ab 0:34

Elementor im WordPress-Plugin-Verzeichnis unter «Beliebt» oder per Suche installieren und aktivieren, dann kurz das Onboarding durchlaufen. Das MCP mit den Elementor-Kernfunktionen ist bereits kostenlos nutzbar.

Für den vollen Funktionsumfang zusätzlich Elementor Pro (liefert dem MCP Pop-ups, Formulare, Komponenten, Theme-Teile, dynamische Inhalte u. a.) und Angie (eigene Widgets, Anpassen des WordPress-Admins, Massenbearbeitungen an Produkten/Beiträgen, Steuerung anderer Plugins über die WordPress Abilities API).

02

MCP-Verbindung herstellen

ab 1:00

Auf der neuen MCP-Verbindungsseite in WordPress «Elementor MCP» anklicken, die Connector-Seite aktivieren und die Zielanwendung wählen: Claude Code, Claude Desktop, Codex, Cursor oder andere.

Pro Tool der gleiche Ablauf: bestätigen, dass im Hintergrund ein Application Password generiert wird → Prompt generieren (wird automatisch kopiert) → in das KI-Tool einfügen und absenden. Wichtig: die KI-App danach neu starten, bevor der nächste Prompt kommt, damit die Verbindung vollständig steht.

03

Ergebnis testen

ab 2:31

Zur Demonstration legt jedes Tool eine neue Seite «Built with …» mit einem beliebigen Hero-Bereich an. Zurück in WordPress erscheinen drei Seiten: built with Claude, built with Codex, built with Cursor.

Im Elementor-Editor zeigt sich: echte, voll bearbeitbare Elementor-Elemente, wie selbst gebaut. Weiterarbeiten geht per Prompt (neue Sektionen/Seiten/Änderungen) oder manuell im Editor. Cursor ergänzte eigenständig eine kleine Animation, ohne dass danach gefragt wurde.

04

Zugänge verwalten

ab 3:58

Die generierten Application Passwords werden in den WordPress-Benutzereinstellungen verwaltet – eines pro KI-Tool. Sie lassen sich jederzeit widerrufen oder neu generieren.
